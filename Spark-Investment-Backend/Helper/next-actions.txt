## 🎯 **Immediate Next Steps (This Week)**

### **Priority 1: Portfolio & Investment Models**

**Start with database models - Foundation for everything else!**

#### **Action Items for Tomorrow:**

1. **Create Portfolio Schema** (2 hours)
```prisma
model Portfolio {
  id              String    @id @default(uuid())
  userId          String    @map("user_id")
  totalValue      Decimal   @map("total_value")
  investedAmount  Decimal   @map("invested_amount")
  currentValue    Decimal   @map("current_value")
  returns         Decimal
  returnsPercent  Decimal   @map("returns_percent")
  lastUpdated     DateTime  @map("last_updated")
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt
  
  user            User      @relation(fields: [userId], references: [id])
  platforms       Platform[]
  investments     Investment[]
  
  @@map("portfolios")
}
```

2. **Create Platform Schema** (1 hour)
```prisma
model Platform {
  id            String    @id @default(uuid())
  portfolioId   String    @map("portfolio_id")
  name          String    // "Zerodha", "Groww", etc.
  type          String    // "trading", "mutual_fund", "crypto"
  connected     Boolean   @default(false)
  apiKey        String?   @map("api_key")
  apiSecret     String?   @map("api_secret")
  lastSyncAt    DateTime? @map("last_sync_at")
  createdAt     DateTime  @default(now())
  
  portfolio     Portfolio @relation(fields: [portfolioId], references: [id])
  investments   Investment[]
  
  @@map("platforms")
}
```

3. **Create Investment Schema** (2 hours)
```prisma
model Investment {
  id              String    @id @default(uuid())
  portfolioId     String    @map("portfolio_id")
  platformId      String    @map("platform_id")
  type            InvestmentType
  symbol          String
  name            String
  quantity        Decimal
  avgBuyPrice     Decimal   @map("avg_buy_price")
  currentPrice    Decimal   @map("current_price")
  investedAmount  Decimal   @map("invested_amount")
  currentValue    Decimal   @map("current_value")
  returns         Decimal
  returnsPercent  Decimal   @map("returns_percent")
  purchaseDate    DateTime  @map("purchase_date")
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt
  
  portfolio       Portfolio @relation(fields: [portfolioId], references: [id])
  platform        Platform  @relation(fields: [platformId], references: [id])
  transactions    Transaction[]
  
  @@map("investments")
}

enum InvestmentType {
  MUTUAL_FUND
  STOCK
  CRYPTO
  ETF
  BOND
  GOLD
}
```

4. **Update User Model with Relations** (30 min)
```prisma
model User {
  // ... existing fields ...
  portfolios      Portfolio[]
}
```

5. **Run Migration** (15 min)
```powershell
cd node-service
npx prisma migrate dev --name add_portfolio_investment_models
npx prisma generate
```
